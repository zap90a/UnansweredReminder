Отслеживает диалоги, в которых последнее сообщение от покупателя остаётся без ответа, и отправляет напоминание в Telegram с inline-кнопками.

## Возможности

- ⏱ Автоматический мониторинг всех диалогов (или только заказов)
- 🔔 Уведомление в Telegram при превышении таймаута
- ✅ Кнопка «Я ответил» — помечает диалог отвеченным
- 🔇 Кнопка «Игнорировать» — добавляет чат в игнор-лист
- ⚙️ Настройки через inline-клавиатуру:
  - Вкл/Выкл плагина
  - Таймаут (30 сек – 30 мин)
  - Режим проверки (все диалоги / только заказы)
  - Повторные уведомления с настраиваемым интервалом
  - Исключение закрытых заказов
  - Игнорирование системных сообщений
- 🔗 Кликабельная ссылка на чат в уведомлении
- 📊 Статистика и очистка устаревших записей

## Установка

1. Скачай `UnansweredReminder.py`
2. Помести в папку `plugins/` твоего Cardinal
3. Перезапусти Cardinal

Плагин подключится автоматически.

## Команды

| Команда | Описание |
|---|---|
| `/unanswered toggle` | Вкл / Выкл плагин |
| `/unanswered timeout 5` | Таймаут 5 минут |
| `/unanswered timeout 30s` | Таймаут 30 секунд |
| `/unanswered mode all` | Проверять все диалоги |
| `/unanswered mode orders` | Проверять только заказы |
| `/unanswered ignore 12345` | Добавить чат в игнор |
| `/unanswered silence` | Игнорировать текущий чат |
| `/unanswered stats` | Показать статистику |
| `/unanswered cleanup` | Очистить устаревшие записи |
| `/list` | Список неотвеченных диалогов |
| `/cleanup` | Очистка (сокращение) |

> **Важно:** Команды `/list` и `/cleanup` — это короткие алиасы. После перезапуска отправь `/list`, чтобы плагин запомнил твой Telegram chat ID. Без этого уведомления не будут приходить.

## Первый запуск

1. После перезапуска Cardinal отправь боту команду `/list`
2. Плагин захватит твой Telegram ID (в логах: `admin_chat_id захвачен из /list`)
3. Теперь при появлении неотвеченного диалога придёт уведомление

## Уведомление

При превышении таймаута приходит сообщение:

```
⏰ Нет ответа в чате!
👤 Пользователь: ..
🆔 ID чата: ....
🔗 https://funpay.com/chat/?node=.....
📦 Заказ: Нет
⏳ Без ответа: .. мин.
```

Кнопки в уведомлении:

- **✅ Я ответил** — помечает диалог отвеченным, уведомление удаляется
- **🔇 Игнорировать** — чат добавляется в игнор-лист, уведомление удаляется
- **📋 Инфо** — информация о чате (ID, ожидание, количество напоминаний)
- **⚙️ Настройки** — меню настроек плагина

## Настройки

Настройки параметров доступны через inline-клавиатуру в уведомлении или после нажатия кнопки «Настройки» в списке плагинов.

- **Таймаут:** 30 сек / 1 мин / 3 мин / 5 мин / 10 мин / 15 мин / 30 мин
- **Интервал повтора:** 1 мин / 3 мин / 5 мин / 10 мин / 15 мин / 30 мин / 60 мин
- **Режим:** все диалоги / только заказы
- **Исключать закрытые:** Да / Нет
- **Игнорировать системные:** Да / Нет

Все настройки сохраняются в `storage/unanswered_reminder/config.json`.

## Требования

- Python 3.8+
- FunPay Cardinal v0.1.17.9
- telebot (pyTelegramBotAPI) — встроен в Cardinal
